# FinderTools — расширение контекстного меню Finder для macOS

Finder Sync Extension, которое добавляет в меню по правой кнопке мыши (и кнопкой на панель инструментов Finder):

| Раздел | Что делает |
|---|---|
| **Новый файл** | txt, md, rtf, пустой файл, json, yml, csv, html, css, js, py, swift, sh, .gitignore. Скрипты сразу получают `chmod +x`. Ещё есть пункт **«Из буфера обмена»**: текст сохраняется в .txt, картинка в .png |
| **Скопировать путь** | полный путь (если выделено несколько файлов, каждый путь на своей строке) |
| **Скопировать…** | имя, имя без расширения, путь в кавычках для Терминала, путь от `~`, путь к родительской папке, ссылка `file://`, содержимое файла, SHA-256 |
| **Открыть в** | Терминал, iTerm, Warp, Ghostty, VS Code, Cursor, Zed, Sublime Text, Xcode (показываются только установленные) |
| **Ещё** | `chmod +x`, создание символической ссылки |

## Окно настроек
Если открыть приложение FinderTools, появится окно с вкладками:
- **Меню**: включение и выключение каждого пункта, а также режим «спрятать всё в подменю FinderTools»
- **Шаблоны**: какие типы файлов показывать в «Новый файл»
- **Приложения**: какие программы показывать в «Открыть в» (неустановленные недоступны)
- **Расширение**: включено ли расширение и кнопка перехода в системные настройки

Настройки лежат в `~/Library/Application Support/FinderTools/settings.json` и применяются сразу, перезапускать Finder не нужно.

Куда создаётся новый файл: если выделена одна папка, то внутрь неё, иначе в текущую папку.

## Требования
- macOS 13+
- Xcode 15+
- [XcodeGen](https://github.com/yonaskolb/XcodeGen): `brew install xcodegen`

## Быстрая установка
```bash
./build.sh
```
Скрипт сгенерирует проект, соберёт его, скопирует приложение в `/Applications`, включит расширение и перезапустит Finder.

## Через Xcode
```bash
xcodegen generate
open FinderTools.xcodeproj
```
Выберите схему **FinderTools** и нажмите Run. Затем включите расширение:
- **macOS 15.2+**: Системные настройки → Основные → Объекты входа и расширения → раздел «Расширения» → FinderTools → включить «Finder»
- **macOS 13–14**: Системные настройки → Конфиденциальность и безопасность → Расширения → Добавленные расширения → FinderTools
- или из терминала: `pluginkit -e use -i com.example.findertools.extension`

Если меню не появилось: `killall Finder`.

## Подпись
По умолчанию используется локальная ad-hoc подпись (`CODE_SIGN_IDENTITY = -`). Её хватает, чтобы пользоваться расширением на своём Mac.
Чтобы раздавать приложение другим, впишите свой `DEVELOPMENT_TEAM` в `project.yml`, поставьте `CODE_SIGN_STYLE: Automatic` и нотаризуйте сборку.
Bundle ID (`com.example.findertools`) лучше заменить на свой.

## Как устроено
- `Extension/FinderSync.swift` — меню и все действия
- `Shared/Model.swift` — общий код приложения и расширения: шаблоны, список приложений, пункты меню, чтение и запись настроек. **Добавить свой шаблон** = дописать строку в `FileTemplate.all`
- `App/FinderToolsApp.swift` — окно настроек

`Info.plist` и `.entitlements` генерируются XcodeGen из `project.yml`, поэтому они не хранятся в git.

Finder Sync-расширение обязано работать в песочнице, поэтому в entitlements добавлено
`com.apple.security.temporary-exception.files.absolute-path.read-write = /`, чтобы можно было создавать файлы в любой папке.
С таким исключением приложение нельзя опубликовать в Mac App Store, но для собственного использования и распространения напрямую оно подходит.

Отладка: логи расширения смотрите в Console.app с фильтром `FinderTools`.
